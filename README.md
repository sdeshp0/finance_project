# Finance Project App
>Welcome to the Finance Project. This is a Python and Streamlit-based application that will allow you to query stock data
from Yahoo Finance, visualize the data and run various analyses.
---
Before you can start, you must make sure you have the Python Anacondas distribution.

>You can install the Anacondas Distribution from here: https://www.anaconda.com/download

Next you must make sure you have all the required packages. A requirements.txt has been provided in the main project
directory.

Follow the steps below to install all the pre-requisites:

1) Navigate to the finance_project directory in the windows explorer and copy the address to you clipboard
2) Open your Anacondas Prompt using the start menu and put the following in the prompt:
   1) Paste the address of the finance_project directory from your clipboard into the Anaconda Prompt where it says
   [PROJECT DIRECTORY]
    > pip install [PROJECT DIRECTORY] -r requirements.txt
3) After entering the above in the prompt, hit ENTER and let the prompt install all required packages
---
Use the run_finance_app.bat file to launch the app. It should open in a browser window.
